# Supermercado União — versão com pagamento na entrega

Esta versão não utiliza checkout online do PagBank. O cliente seleciona cartão de crédito, cartão de débito, dinheiro ou vale-refeição para pagar quando receber o pedido. O pedido é encaminhado ao WhatsApp da loja para confirmação.

O arquivo foi mantido com este nome por compatibilidade com o pacote anterior. Não configure token PagBank para esta versão. Antes de publicar, substitua preços demonstrativos, valide as bandeiras aceitas e configure hospedagem segura e persistência dos pedidos.
